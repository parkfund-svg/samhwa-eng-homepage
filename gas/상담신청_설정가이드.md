# 상담신청 폼 연동 설정 가이드

홈페이지의 "온라인 상담 신청" 폼을 제출하면 **구글 시트에 자동 저장 + 담당자 이메일 알림**이 오도록
Google Apps Script(무료)를 이용합니다. 서버나 호스팅 요금이 들지 않습니다.

지금 상태로도 홈페이지는 정상 작동합니다 — 아래 설정을 하기 전까지는 상담 신청 시
"담당자에게 직접 연락 부탁드립니다" 안내만 뜨고, 구글 시트 저장/이메일 알림은 되지 않습니다.
연동을 원하시면 아래 순서대로 진행해 주세요. (약 10분 소요, 구글 계정 필요)

---

## 1단계. 구글 시트 만들기

1. [sheets.google.com](https://sheets.google.com) 접속 → **새 스프레드시트** 만들기
2. 이름을 "삼화이엔지 상담신청"으로 변경 (선택사항)

## 2단계. Apps Script 코드 붙여넣기

1. 방금 만든 스프레드시트에서 상단 메뉴 **확장 프로그램 → Apps Script** 클릭
2. 기본으로 열려있는 `myFunction() {}` 코드를 전부 지우기
3. 이 폴더의 [`backend-apps-script.js`](backend-apps-script.js) 파일 내용을 전부 복사해서 붙여넣기
4. 필요하면 코드 상단의 설정값 수정:
   - `ADMIN_EMAIL` — 상담 접수 알림을 받을 이메일 (기본값: sh50500@sheng.kr)
   - `ADMIN_PASSWORD` — 관리자 페이지(admin.html) 접속 비밀번호
5. **Ctrl+S**로 저장 (프로젝트 이름 물으면 "삼화이엔지 상담신청 백엔드" 등으로 입력)

## 3단계. 웹앱으로 배포

1. 오른쪽 위 **배포 → 새 배포** 클릭
2. 유형 선택(⚙️ 톱니바퀴) → **웹 앱** 선택
3. 설정:
   - **실행 계정**: 나
   - **액세스 권한**: **모든 사용자**
4. **배포** 클릭
5. 권한 승인 창이 뜨면:
   - "권한 검토" → 구글 계정 선택 → "고급" → "OOO(안전하지 않음)로 이동" → **허용**
6. 배포가 끝나면 나오는 **웹앱 URL**을 복사해 둡니다.
   (`https://script.google.com/macros/s/xxxxx/exec` 형태)

## 4단계. 홈페이지 코드에 URL 붙여넣기

1. `js/main.js` 파일을 열어 아래 줄을 찾습니다:
   ```js
   var CONSULT_WEBHOOK_URL = '';
   ```
   따옴표 안에 3단계에서 복사한 URL을 붙여넣습니다:
   ```js
   var CONSULT_WEBHOOK_URL = 'https://script.google.com/macros/s/xxxxx/exec';
   ```

2. `admin.html` 파일을 열어 아래 줄도 동일하게 수정합니다:
   ```js
   const WEBHOOK_URL = 'https://script.google.com/macros/s/xxxxx/exec';
   ```

3. 저장 후 홈페이지를 다시 불러와 상담 신청 폼을 테스트 제출해 보세요.
   - 구글 시트에 "상담신청" 탭이 자동으로 생기고 데이터가 쌓입니다.
   - 설정한 이메일로 알림 메일이 도착합니다 (스팸함도 확인해 주세요).

## 5단계. 관리자 페이지에서 신청 목록 확인

- `admin.html`을 웹 브라우저로 열고, 2단계에서 설정한 `ADMIN_PASSWORD`를 입력하면
  접수된 상담 목록을 표로 볼 수 있습니다.
- 비밀번호를 바꾸려면 Apps Script의 `ADMIN_PASSWORD` 값과 `admin.html`을 함께 수정 후,
  Apps Script는 **배포 → 배포관리 → 편집(연필 아이콘) → 새 버전으로 배포**해야 반영됩니다.

---

## 코드를 수정한 뒤에는 항상 "새 버전"으로 재배포하세요

Apps Script 코드를 고친 후 저장만 하면 반영되지 않습니다. 반드시:
1. 배포 → 배포 관리
2. 연필(✏️) 아이콘 클릭
3. 버전: **새 버전** 선택 → 배포

이 과정을 건너뛰면 이전 코드가 계속 실행됩니다.

## 문제 해결

- **이메일이 안 와요** → 스팸함 확인, Apps Script 에디터 좌측 "실행" 메뉴에서 오류 로그 확인
- **"비밀번호가 틀렸습니다"라고 나와요** → Apps Script의 `ADMIN_PASSWORD`와 `admin.html`의 비밀번호가 일치하는지, 재배포했는지 확인
- **폼 제출은 되는데 시트에 안 쌓여요** → 웹앱 배포 시 "액세스 권한"이 "모든 사용자"로 되어 있는지 확인
