# 카카오톡 상담 버튼 설정 가이드

홈페이지 우측 하단에 "카카오톡 상담" 버튼을 띄워, 클릭하면 고객의 카카오톡 앱에서
우리 회사 카카오톡 채널과 바로 1:1 대화가 열리도록 하는 기능입니다.

**백엔드(서버) 필요 없음** — 카카오가 채팅 인프라를 전부 호스팅해주고,
사이트에는 채널로 연결되는 링크 하나만 있으면 됩니다.

---

## 1단계. 카카오톡 채널 만들기

1. [business.kakao.com](https://business.kakao.com) 접속 → 카카오 계정으로 로그인
2. **카카오톡 채널 관리자센터 → 채널 만들기**
3. 정보 입력:
   - 채널 이름: `삼화이엔지` (또는 `(주)삼화이엔지`)
   - 검색용 아이디: 예) `@samhwaeng` (다른 사업자가 안 썼다면 원하는 대로 설정 가능)
   - 카테고리: 건설/전기·설비
   - 프로필 사진: 로고(`assets/img/logo.png`) 업로드
4. 사업자 인증(선택) — 사업자등록증으로 인증하면 채널에 "인증 마크"가 붙어 신뢰도가 올라갑니다.
   나중에 해도 무방합니다.

## 2단계. 상담(채팅) URL 확인

1. 채널 관리자센터 접속 → 좌측 **채널 정보** 또는 **채널 홈**
2. **채널 URL** 또는 **채팅 URL**을 확인합니다. 아래와 같은 형태입니다:
   ```
   https://pf.kakao.com/_XXXXXXX/chat
   ```
   (숫자/영문 조합의 `_XXXXXXX` 부분이 우리 채널 고유 ID입니다)
3. 이 URL을 복사해 둡니다.

> 채널 URL이 잘 안 보이면: 관리자센터 홈 화면 상단의 채널명 옆 **"공유하기" → "채널 URL 복사"** 를 이용하셔도 됩니다.

## 3단계. 사이트 코드에 붙여넣기

`js/main.js` 파일 상단에서 아래 줄을 찾습니다:
```js
var KAKAO_CHANNEL_CHAT_URL = '';
```
따옴표 안에 2단계에서 복사한 URL을 붙여넣습니다:
```js
var KAKAO_CHANNEL_CHAT_URL = 'https://pf.kakao.com/_XXXXXXX/chat';
```

저장 후 홈페이지를 새로고침하면 우측 하단에 노란색 "카카오톡 상담" 버튼이 나타나고,
클릭 시 카카오톡 채팅창으로 연결됩니다.

---

## (선택) 자동응답 / 챗봇 시나리오 설정

담당자가 자리를 비웠을 때도 기본 안내가 나가도록 하려면:

1. 채널 관리자센터 → **채팅 → 자동응답**
2. **부재중 응답 메시지** 설정 (예: "안녕하세요, 삼화이엔지입니다. 평일 09:00~18:00에 순차적으로 답변드립니다.")
3. 좀 더 정교한 버튼형 대화 흐름(예: "전기공사 문의 / 소방공사 문의 / 견적 문의" 버튼 선택형)을
   만들고 싶다면 **카카오 i 오픈빌더**(별도 무료 도구, business.kakao.com에서 연결)를 사용하면
   코드 없이 시나리오를 구성할 수 있습니다. 이 역시 카카오 쪽에서 호스팅하므로 우리 서버는 필요 없습니다.

## 문제 해결

- **버튼이 안 보여요** → `js/main.js`의 `KAKAO_CHANNEL_CHAT_URL`이 비어있지 않은지, 오타 없이 붙여넣었는지 확인
- **클릭했는데 채팅이 안 열려요** → PC에서는 카카오톡 로그인 페이지로 갈 수 있습니다(정상). 모바일에서 카카오톡 앱이 설치되어 있으면 앱으로 바로 연결됩니다.
- **채널 인증 마크가 없어요** → 사업자 인증을 아직 안 하신 경우입니다. 관리자센터에서 사업자등록증으로 인증 신청하면 며칠 내 반영됩니다.
